# guia de sistemas operacionias
Utilizar o NotebookLM como ferramenta de aprendizagem ativa para compreender os principais conceitos de Sistemas Operacionais, organizando informações provenientes de fontes confiáveis em um material de estudo prático.

Tema escolhido: Sistemas Operacionais

Este caderno temático tem como foco o estudo dos Sistemas Operacionais, buscando compreender os principais conceitos relacionados ao funcionamento e gerenciamento dos recursos de um computador.

O tema foi escolhido por ser um dos fundamentos da área de Tecnologia da Informação e por estar diretamente relacionado ao uso de computadores, servidores e outros dispositivos.

diretamente relacionado ao uso de computadores, servidores e outros dispositivos.

 Objetivos

Os principais objetivos deste estudo são:

Compreender o que é um Sistema Operacional e qual é sua função;
Conhecer os principais componentes e responsabilidades de um Sistema Operacional;
Entender o gerenciamento de processos e threads;
Compreender como ocorre o gerenciamento de memória;
Conhecer os principais conceitos relacionados a sistemas de arquivos;
Entender como o Sistema Operacional se comunica com dispositivos de hardware;
Utilizar o NotebookLM como ferramenta de apoio à pesquisa, organização e revisão do conteúdo;
Desenvolver uma base de conhecimento que possa ser utilizada posteriormente para revisões e estudos.
